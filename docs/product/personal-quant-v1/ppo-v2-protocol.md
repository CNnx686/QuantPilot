# PPO 持仓状态研究：运行前固定协议

2026-11-17。目标：检验当前 PPO 只观察价格、不知自己是否持仓是否可能增加无效动作和种子敏感性。此为待检验假设，结果不承诺改善。

- 数据：Binance BTC/USDT 1h 公共现货，窗口按 UTC 左闭右开：2025-01-01 → 01-15、01-15 → 01-29、04-01 → 04-15、07-01 → 07-15。每窗按原引擎约 70% 训练、30% 评估；前两窗已观察，后两窗是本研究额外开发留出，见到结果后仍不是最终盲测。2025 Q4 不使用。
- 每窗 seed 7、42、99、17、52。对照为原 6 维价格 PPO；研究版增加第 7 维为决策时由逐时账本得到的持仓 0/1。训练和评估采用同样价格、资金、手续费、止损、网络层、学习率、步数、种子；不使用评估期选择检查点。
- 第 7 维在每步成交执行之后、下一决策之前读取当前账本；评估逐时运行，不能用未来价格或预先计算的持仓序列。
- 每模型 2048 步，初始 10000 USDT，每次 1000，单边费用 0.1%、5% 收盘止损、下一小时开盘成交。无完整滑点、盘口冲击。两臂算力预算相同，但新增一维使首层参数略多。
- 报告各种子/窗口/臂净收益、最大回撤、交易数、换手，以及被持仓状态阻止的买入/卖出比例（包含末根没有下一开盘的动作需单独说明）；不只挑选最佳。保留失败和不可比记录。
- 前两窗的十个基线可复用上一轮已封存的同种子价格模型，但必须核验源文件哈希和配置；新增两窗重新训练基线和研究版。所有改进只作研究，不发布或接入模拟，除非额外验证支持并单独完成模型封存和当前推理兼容。
