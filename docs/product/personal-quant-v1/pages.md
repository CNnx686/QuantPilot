# 页面结构与交互规格

## 1. 布局约定

暗色中文桌面终端；以多面板和密集表格组织信息，不使用营销首页或大面积介绍卡片。目标桌面视口约 1440×900，兼容 1260 宽；更窄窗口保留有序滚动，不将移动端适配作为本期核心。

上述尺寸是工程设计目标，不是用户指定的设备信息。配色以深灰蓝、青绿强调色和克制的涨跌色构成，数值等宽对齐，状态不能只靠颜色表达。演示模式始终标明。首版无盘口、逐笔成交和自由手动下单组件，避免出现无法履行业务的装饰性按钮。

## 2. 五个工作区

| 工作区 | 用户问题 | 主要内容 | 主要动作 |
|---|---|---|---|
| 策略工作台 | 哪些策略在运行？现在发生什么？ | 自选/实例列表、品种行情图、策略动作与模型、新闻风险、订单/持仓/成交/日志 | 选实例、启动、暂停、恢复、处理持仓、停止、申请模型切换 |
| 策略管理 | 如何创建或调整自己的策略？ | 策略模板、草稿、版本、单品种配置、资金及参数 | 新建、编辑草稿、复制、保存、转训练或回测 |
| 训练与回测 | 模型训练到哪了？哪个版本可用？ | 任务状态、候选模型、同条件结果、费用与数据区间 | 训练/回测、取消、比较、选定版本、转运行 |
| 新闻与因子 | 新闻从哪里来，怎样进入策略？ | 事件/来源/时间、币种关联、数值因子、覆盖、风险规则、开关对照 | 筛选、查看来源、为草稿启用新闻、比较两组实验 |
| 数据与设置 | 数据够不够？哪里出问题？ | 数据区间、下载任务、市场连接、新闻源健康、本机资源、可选 LLM | 准备数据、查看故障、配置非秘密选项；DeepSeek 本机后续配置 |

报告、诊断、冻结证据作为相应策略/实验的详情，不再迫使用户先理解多个后台审计页面才能操作。

## 3. 工作台结构

```text
┌ 品牌 / 五工作区导航 ─────────── 模式 / 连接与数据状态 ┐
├ 自选品种 / 策略实例 ┬ 当前品种、报价、模型版本 ┬ 决策 / 控制 ┤
│ 运行状态与简要盈亏  │ 小时 K 线、指标、买卖点   │ 新闻 / 风险 │
│ 当前所选实例       │ 成交量、缩放/平移         │ 模型切换    │
├───────────────────┴─────────────────────────┴─────────────┤
│ 持仓 / 订单 / 成交 / 日志：仅展示当前实例                    │
└ UTC 数据时间 / 新鲜度 / 当前版本 / 虚拟资金独立说明          ┘
```

选择实例是关联上下文的主动作。品种、模型、图表成交点和底部记录必须同步；不允许 ETH 图表显示 BTC 实例的持仓。若提供独立自选看图，必须醒目标注“观察模式”，隐藏不匹配实例的成交点，并清楚保留运行控制所属实例；不能悄悄改变策略交易品种。原型可采用更简单的同币种实例联动，或没有对应实例时引导创建。

运行中实例的“编辑”指向草稿/新版本；不能直接改掉当前运行参数。策略原始动作、风险规则作用、最终执行反馈分开呈现，不能把“买入信号”标为“已成交”。

## 4. 策略创建

三类模板：规则、RL、预测模型。共同字段：名称、单品种、数据区间、虚拟资金、单笔投入/风险参数；模型类型附带训练配置。默认合理值帮助开始，高级参数折叠，不要求 Python 编程。

必需反馈：空名称、非法区间、非正资金、单笔投入超过资金、不支持品种、数据不足或新闻无覆盖。禁止通过仅前端限制宣称生产安全；正式后端重复校验。

创建完成后明确下一动作：规则去回测，RL/预测去训练。训练成功不自动替换运行模型；候选版本要与已选版本分开。

## 5. 运行与版本切换

- 启动：模型/数据/配置技术检查通过，用户明确启动；历史亏损不是唯一拒绝条件。
- 暂停新开仓：允许已有持仓按既定风控继续管理。
- 关闭模拟持仓：显式确认，等待引擎反馈，不能先清空 UI 再假定成交。
- 停止：无持仓时直接停止；有持仓时提供“等待平仓后停止”或“明确关闭模拟持仓后停止”。等待期间禁止新开仓，旧模型继续管理持仓；关闭失败时保留原持仓与管理，不静默平仓或留下无人管理的持仓。这是原型采用的工程默认，待实际交互评审。
- 升级 A：新模型进入待切换状态，旧模型管理已有持仓，平仓后才切换。
- 升级 B：明确确认关闭模拟持仓；关闭成功后切换，失败则保留旧模型并显示原因。
- 新闻故障：依赖新闻的实例暂停新开仓，持仓继续按预设风控；不静默换成价格模型。恢复后采用何种恢复动作在技术设计中明确展示，初版保守采用人工恢复。

## 6. 原型与真实系统的区别

原型将用标为“演示”的状态模拟以上路径。图表数据固定、训练时间压缩，模拟持仓操作只修改本浏览器演示状态。新闻图表和比较数值也是场景数据。原型不能证明交易连接、模型收益、新闻覆盖或故障恢复真实可靠；这些属于验收清单中的生产业务项。
