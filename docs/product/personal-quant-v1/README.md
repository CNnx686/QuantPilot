## 打开交互原型

在项目目录运行 `prototypes\terminal-v1\launch.cmd`，浏览器访问 `http://127.0.0.1:8770/`。原型也支持直接打开该目录的 `index.html`；推荐 HTTP 方式使用，避免不同浏览器对本地文件存储行为不同。

原型使用确定的演示数据，训练进度、模型结果、下载状态、新闻与订单都是交互场景；**不连接交易所、不调用 DeepSeek、不训练模型、不连接原项目交易引擎**。它验证布局与操作语义，不作为回测收益或真实执行证据。

原型状态保存在当前浏览器独立 localStorage 命名空间，可通过“重置演示”恢复。不会修改原项目 SQLite、模型或实验。停止预览服务运行 `prototypes\terminal-v1\stop.cmd`。

## 建议试用顺序

1. 在工作台选择 BTC RL 与 ETH 规则策略，观察图表、信号、持仓、订单、日志联动。
2. 新建一个 RL 策略，填入品种、区间、参数和资金；检查无效输入提示。
3. 进入训练与回测，启动明确标注的演示任务，查看候选结果并选定版本。
4. 启动该实例的演示模拟，尝试暂停、恢复、关闭模拟持仓和停止。
5. 在新闻与因子中查看事件与数值因子、行情/行情＋新闻对照；不要把演示对照数字当成模型能力。
6. 对已有持仓的 BTC 实例申请新模型，体验“等待平仓后切换”和“显式平仓后切换”。
7. 检查数据与设置中的数据准备、新闻故障状态；DeepSeek 保持未配置。

原型确认时重点反馈：哪些信息应在同一屏、哪个动作难找、创建策略是否自然、模型与新闻作用是否看得懂。生产实现将接入真实数据与引擎，并逐项执行真实系统验收。

当前原型用七个固定现货品种和 2025-01-01 至 2025-07-01 的演示窗口说明流程。图表用按钮缩放、底部滑块平移；成交点按本实例记录示意定位。完整品种检索、自定义真实数据下载、图表直接拖拽、任务排队/取消/失败、助手和自动研究仍属于后续实现，不能将该原型当作这些能力的完成证明。
