# QuantPilot 答辩演示操作流程

适用版本：C 盘恢复版，2026-10-23 实际验收。项目根目录 `C:\Users\20705\QuantPilot-Restored`。下文结果是 C 盘重新生成的实验，不是已损坏 D 盘原始运行结果。测试与已知限制见 [本轮验收](defense-acceptance-20261023.md)。

## 1. 一句话说明项目

“QuantPilot 把研究想法转换成可确认的实验规格，再经过真实历史回测、同条件比较、证据审核，决定能否进入虚拟资金模拟，并保留可追溯的报告和历史回放。”

业务主线：**想法 → 草稿 → 人工确认 → 持久化任务 → Freqtrade 回测 → 原始产物核验 → 比较/诊断 → 不可变发布审核 → SMA 模拟部署 → 报告/回放。**

扩展线：公开新闻 → 带来源与可知时间的研究草稿；多交易所 → 公开行情观察；独立 PPO → 五种子研究与真实引擎重放；实盘控制 → 默认关闭的准入实现。

这里有三种不同的 AI：DeepSeek 可选地生成研究规格；FreqAI + LightGBM 做历史收益回归；独立 PPO 学习交易动作。三者不等价，当前演示不需要在线大模型密钥。

## 2. 演示前 15 分钟

1. 接通电源，保持电脑不休眠。使用 C 盘项目，勿访问故障 D 盘。
2. 双击根目录 `launch.cmd`，或在 PowerShell 中运行：

   ```powershell
   cd C:\Users\20705\QuantPilot-Restored
   .\launch.cmd --no-browser
   ```

3. 打开 `http://127.0.0.1:8765/`。到“数据与系统”检查主引擎、前端、数据库、worker、数据集。可选 LLM 未配置不是主链路故障。
4. 到“证据报告”打开下文 SMA、FreqAI 两个指定实验，确认报告可读取。到“RL 实验室”等待“隔离训练环境可用”，先加载已完成任务。
5. 网络可用时提前刷新交易所观察以及 ECB/Fed 新闻；不要把答辩时间用于等外部请求。CoinDesk 当前抓取失败，可直接展示失败状态后使用 ECB。
6. 打开备用文件夹 `artifacts\defense-pack-20261023`：里面的 `sma-q2.html`、`freqai-q2.html`、`freqai-q3.html` 可以脱离服务和网络浏览、打印为 PDF。`index.json` 保存导出文件 SHA256。这是一份验收时快照，不会自动更新。
7. 不运行安装脚本，不清空数据库，不重新训练 PPO，不下载最终测试集。现场新建实验可以展示任务提交，但准备好切到已完成结果。

两人分工：A 操作界面、记住实验名称与备用路径；B 解释业务逻辑、指标口径和边界、回答问题。可提前录一段本机操作视频作备用，并标明录制日期；本次未代录视频。

### 第一步：把想法变成可审核规格

1. 打开“研究助手”，使用本地模板，输入 **`BTC ETH SMA trend baseline`**，点击“生成可审阅规格”。本地模板是受限规则解析，别在这句话前加中文前缀；中文名称在生成后编辑。
2. 查看交易对 BTC/USDT、ETH/USDT，周期 1h，SMA 策略，区间 **2025-04-01 至 2025-07-01（不含当天）**，UTC。
3. 将实验名称改成“现场演示 · SMA 2025Q2”，检查资金、手续费和假设后“保存草稿”。
4. 点击“确认此版本并运行回测”。应跳到工作台，出现独立任务 ID、queued/running，完成后 succeeded。刷新页面不会丢失任务。
5. 等待期间解释：前端不直接控制交易；服务端校验并冻结配置，worker 领取任务，调用真实引擎。错误会保留失败状态，不补造收益。
6. 若网络或执行时间影响现场节奏，切换已经完成的 **“答辩演练 · SMA 2025Q2”（f37527ed）**。它在本轮由界面完整创建，并重新跑出了 60 笔成交。

建议讲述：“AI/模板负责提出规格，确认后的受约束执行链负责实验。生成文字不等于执行，更不等于交易建议。”在线 DeepSeek 当前未配置，也未实测；不要宣称现场调用过在线模型。

### 第二步：同条件比较，保留失败结果

进入“实验对照”：A 选 **答辩演练 · SMA 2025Q2**，B 选 **前视边界修复复验 · FreqAI 2025Q2**。

| 本轮可复查的历史结果 | 成交 | 净收益 | 已平仓账户最大回撤 |
|---|---:|---:|---:|
| SMA，2025Q2 | 60 | +2.2268% | 3.0342% |
| FreqAI，2025Q2 | 211 | -1.1864% | 3.3502% |
| FreqAI，2025Q3（补充展示） | 160 | +1.0465% | 2.1408% |

Q2 初始资金 10,000 USDT，单笔名义投入 1,000，手续费每边 0.1%；SMA 期末余额 10,222.68。SMA12/SMA48 与六小时收益回归不是同一类策略，比较控制的是数据、资金、费用与区间。模型输出是收益估计，不是上涨概率。

展示月度已实现损益和费用压力测试。解释余额曲线不含未平仓浮动盈亏，月度损益按平仓月份归类；附加手续费压力是固定原成交路径的后处理，不能模拟改变成交后的路径。可以将 B 换为 Q3，观察不兼容提示，然后换回 Q2；不可拿跨季度收益直接判优。

建议讲述：“我们没有让 AI 一定赢。模型在这个开发季度亏损，系统仍如实展示；工程正确性与预测有效性分开评价。”

3. 点击“下载 HTML · 可打印”或“下载 JSON”；HTML 打开后 Ctrl+P 可保存 PDF。每次导出都重新核对原始文件，损坏不会继续生成正常报告。

## 5. 断网与故障应对

| 现象 | 操作与说明 |
|---|---|
| 网页无法连接 | 运行 launch.cmd，查看 runtime 日志；不要重复手动启动多个 worker |
| 回测排队 | 确认 worker 心跳；新回测仍依赖交易所公共 market 元数据，网络不通则切已完成结果 |
| 模拟 starting/不可用 | 等待一次正常启动；失败时保存错误并停止该实例，演示历史记录；不要显示为实时运行 |
| 模拟没有成交 | 正常情况，展示闭合 K 线信号，再用明确标注的历史回放展示交易 |
| CoinDesk 失败 | 使用 ECB/Fed；已有新闻可浏览，失败状态不伪装成最新成功 |
| LLM 未配置 | 使用精确本地模板输入；本地提取与确定性报告无需 API 密钥 |
| RL 检查较慢 | 提前打开等待；直接展示已有结果，勿把缓存训练说成刚刚重训 |
| 无网络 | 主服务仍可展示已保存实验、比较、报告、回放、缓存新闻/行情、RL 结果；不启动需要联网的刷新或模拟 |
| 服务也无法启动 | 直接打开离线包 HTML；明确说明这是 10 月 23 日验收导出，不是假装在线操作 |
| 报告显示证据错误 | 不绕过校验。使用已核验离线报告并保留错误供排查 |

结束时先停止当前模拟部署，确认 stopped，再执行根目录 `stop.cmd`。关闭网页不会停服务。若实验仍运行，停止服务会中断任务；不要为了清场删除数据库。

## 6. 常见追问与回答

- **AI 为什么输给 SMA？** 数据与协议下模型没有显示优势；当前目标是可复查研究，不是筛选漂亮收益。下一步应冻结方法，再做独立最终测试或前向模拟。
- **怎么防止未来数据泄漏？** 特征与标签可知时间、训练边界、训练内预处理、下一根执行时序、抽样对照和原始产物共同约束；单次前视检查不能证明一切。
- **为什么 Q4 没跑？** 保留最终测试不参与开发；Q2/Q3 已用于调试，不能再叫未见盲测。
- **收益可靠吗？** 数字来自实际引擎和保存的成交文件，软件已核对；OHLC 回测不完整模拟盘口、延迟、滑点和冲击，所以不能外推实盘收益。
- **能真实交易吗？** 有默认关闭的控制实现，真实账户及订单未验收；本次可验证的是历史研究和虚拟资金链路。
- **新闻真的用于预测了吗？** 当前用于带来源的研究假设，未把今天新闻塞进历史特征；本地规则提取不是在线 LLM。
- **多交易所是什么程度？** Binance/OKX/Kraken 的公开数据观察与缓存；主回测/模拟仍用 Binance，实盘框架也不是三家全通。
- **可重复吗？** 保存了版本、配置、数据与文件哈希。本轮 SMA 重跑指标与原 C 盘重建实验一致；这不代表随机 ML 在任意硬件绝对逐位相同。
