# QuantPilot 第二周实施计划

> 使用 subagent-driven-development，逐项实现、规格审查与质量审查；延续现有 D 盘目录和第一周数据。

**Goal:** 真实 FreqAI/LightGBM 滚动训练、标签时间审计、同条件规则/ML 对比和可演示页面。
**Architecture:** 保持 React → FastAPI → SQLite → worker → Freqtrade。模型使用自定义的 FreqAI 模型适配以在拟合前清除尚不可知标签并输出审计证据。旧实验和原始数据不覆盖。
**Tech Stack:** 现有 Python 3.13 / Freqtrade 2026.9 / React，新增锁定的 CPU LightGBM 与 FreqAI 所需依赖。

## 先冻结的研究协议

- 小时现货 BTC/USDT、ETH/USDT。官方历史数据扩充为 2023-12-01 至 2025-10-01；独立新快照。
- 原 2025Q1 已用于工程调试。第二周开发区间为 2025-04-01 至 2025-07-01，验证区间为 2025-07-01 至 2025-10-01。
- 最终测试预留 2025-10-01 至 2026-01-01，本周不下载、不运行，也不依据该段结果改动方案。
- 预设滚动训练 90 天、重训间隔 30 天；以安装版本实际切片为准记录每折时间，训练标签必须在预测窗口开始前可知。
- 目标为未来 6 根小时收盘收益；特征只使用当时及过去 OHLCV，固定小规模树模型和随机种子，不进行参数搜索。候选数 1，全部调试/失败任务保留。
- 规则与 ML 使用相同数据快照、区间、资金、费率、交易对、撮合和止损。ML 入场预测收益 >0.3%，退出预测收益 <0，且 do_predict == 1；最终取值在首次训练前写入代码与协议。
- 每边 0.1% 费用，初始资金 10,000 USDT、单笔 1,000。沿用已实现余额与引擎账户回撤口径，不虚构滑点。
