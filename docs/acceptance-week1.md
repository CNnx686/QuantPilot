## 真实实验

- 主实验：`5e890f63-6ab1-41d2-8489-bb449a703cc1`，名称「第一周验收 · 双币种趋势基线」。
- 重复实验：`23718a63-1449-40ab-a1f5-0031f8a34ceb`。
- 数据集：`binance-2025q1-ea520826a66c`。
- 区间：UTC `[2025-01-01, 2025-04-01)`，前一月为预热；BTC/USDT + ETH/USDT，1h。
- 策略：SMA12/48 趋势交叉，5% 止损；初始资金 10,000 USDT，单笔 1,000 USDT，单边手续费 0.1%。

| 成交数 | 57 |
| 扣费后损益 | −566.62092779 USDT |
| 净收益率 | −5.6662092779% |
