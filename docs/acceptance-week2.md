# 第二周验收：FreqAI 与一致评测

完成于 2026-10-11，项目目录 `D:\QuantPilot`，分支 `feat/week2-freqai`。冻结协议先于实验提交（`b3f71f1`），未进行超参数搜索。第一周数据、实验和代码版本均保留。

## 可演示的业务

网页选择 SMA 或 FreqAI → 选择开发/验证区间 → 独立 worker 训练并回测 → 查看资金、成交、模型与时间证据 → 同条件对照 → 阅读专项检查及原始文件。错误数据版本会真实失败，条件不一致的实验被拒绝直接比较。

模型：Freqtrade/FreqAI 2026.9 + LightGBM 4.7.0，自定义 `PurgedLightGBMRegressor`。依赖固定，scikit-learn 1.9.1、DataSieve 0.1.9；XGBoost 3.4.1 仅用于满足该安装版本上游日志模块导入依赖，实际训练的是 LightGBM。CPU 两线程，无 GPU、真实账户或付费模型 API。

## 数据与固定协议

- 新快照 `binance-week2-aac4f6c20b47`，BTC/ETH 各 16,080 根真实小时行情；区间 UTC `[2023-12-01, 2025-10-01)`。官方归档 CHECKSUM、缺失/重复/非有限值检查通过，旧文件不覆盖。
- 已使用的 2025Q1 继续视为开发数据。2025Q2 为本轮开发、2025Q3 为验证。2025Q4 预留最终测试，本轮未下载、未运行。
- 滚动训练 90 天，每 30 天重训；这是预先定义的 walk-forward 流程。后续拟合可以使用之前验证时段内已知的标签，不是整个验证季度冻结同一模型；规则和参数不依据验证结果修改。
- 八个因果特征：1/6/24 小时历史收益、12/48 小时均线偏离、24 小时波动、相对成交量及振幅。目标是 `close[t+6] / close[t] - 1`，不是上涨概率。
- 在拟合和预处理前，要求标签可用时刻 `K线开盘时间 + 7小时 <= 拟合截止`。每折剔除 6 行，2,154 行实际训练。预处理仅拟合训练集；无效或非有限预测不能触发信号。
- 固定 100 棵树、15 叶、深度 5、最小叶样本 40、学习率 0.05、seed 42。入场预测 >0.3%，退出预测 <0，止损 5%。仅一个固定 ML 候选，工程失败保留，无“试到盈利”为止的搜索。
- 两策略同交易对、数据、时间、资金、费用、撮合规则；初始 10,000 USDT、单笔 1,000、每边手续费 0.1%。

## 专项检查：保留原始结果

SMA 开发期 lookahead-analysis 抽查 20 个信号，原始 `has_bias=False`，进出场偏移均为 0。此结果不覆盖所有可能信号。

ML 开发期同样抽查 20 个信号，**原始 `has_bias=True` 保留为 flagged**。进出场偏移均为 0，指标列包括目标、均值/标准差、do_predict 和进出场标签。不能将这些标记全部解释成有意构造的未来标签。

进一步核查安装源码与保留产物发现：上游诊断加载结束 K 线时包含末端，而 FreqAI 预测切片使用 `< stop`；合并结果时末端缺失预测被补零，所以末端 do_predict 和信号列也不同。全部 6,804 条实际产生的诊断预测按交易对/模型/决策时间匹配原实验，预测及有效性完全一致，其中 2,436 条来自 40 个截断运行。该证据只覆盖 4 月 1—7 日、第一折的截断检查，不证明后续所有折或全部因果性。

- SMA 诊断目录：`artifacts/diagnostic-9847f13f-05db-40cb-a1ea-a25861ba7c40/`。
- ML 诊断目录：`artifacts/diagnostic-cfbabba7-f558-4a95-9341-81560b1e6c67/`。
- 补充报告：ML 诊断目录中的 `boundary-audit.json`，通过网页与原始 CSV/日志一起下载。
- 可重复执行的只读核对：`.venv\Scripts\python.exe scripts\audit_diagnostic_prefix.py`。此脚本针对以上固定验收产物，不是任意实验通用分析器。

[官方 lookahead 文档](https://www.freqtrade.io/en/stable/lookahead-analysis/)说明 FreqAI 目标列可能产生标记且抽查存在覆盖限制；本次末端行解释另外依据安装源码和实际产物，未据官方说明直接将所有标记清零。
