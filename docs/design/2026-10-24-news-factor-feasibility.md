# 新闻训练因子 C：初步可行性核查

日期：2026-10-24。结论：**历史标题/事件数值因子的试验可行，已验证部分真实历史记录可访问；连续覆盖、数据质量、训练有效性和收益改善尚未验证。** 这是一份数据与工程核查，不是模型效果报告。

## 1. 实际做过的访问检查

两个公开 GDELT GKG 归档仅在内存中下载解析，没有登录、付费查询、安装依赖、建立训练数据集或运行模型。

直接来源：[1 月批次](https://data.gdeltproject.org/gdeltv2/20250120120000.gkg.csv.zip)、[10 月批次](https://data.gdeltproject.org/gdeltv2/20251001120000.gkg.csv.zip)。10 月探针位于旧项目保留 Q4 范围，只作公开源可访问性检查，没有训练/评估；**不纳入开发样本或后续实验**。开发数据试验优先使用保留区间外的样本。

关键词匹配只证明可找到相关标题，不能证明归类正确或覆盖完整。样本含推广内容与转载，需清洗、去重和实体判断。

## 2. 为什么可作为候选

[GDELT 数据入口](https://gdeltproject.org/data.html)提供免费公开原始文件；GKG 2.0 按 15 分钟更新，包含主题、实体、语气等元数据。[官方标题字段说明](https://blog.gdeltproject.org/gkg-2-0-now-includes-page-titles/)确认 2019 年开始保存 PAGE_TITLE，可研究历史标题而不必回访今天可能已修改的新闻正文。这不是完整历史正文库。

新闻元数据的可用性不等于获得新闻正文的再分发权。首版优先保存必要标题、来源、事件字段和指纹，不抓取或复制全文；实际数据使用条件另见[官方条款](https://gdeltproject.org/about.html#termsofuse)。

## 3. 必须说明的时间限制

[GKG 2.1 官方字段说明](https://data.gdeltproject.org/documentation/GDELT-Global_Knowledge_Graph_Codebook-V2.1.pdf)及样本表明，批次时间不能直接视为本系统当时收到新闻的准确时刻。需分开记录：源声明发布时间、归档批次时间、实际获取时间、时间证据质量。

历史研究可按“归档批次 + 明示延迟假设”对齐，另做延迟敏感性检验，并标为归档回溯研究。当前运行则记录真实收到、解析完成的时刻，才能形成更强的以后回放依据。不能把今天取得的新闻伪装成本系统过去就已采集。

今天的大模型可能知道历史事件后续走势。限定提示词只读旧标题不能证明没有这种知识影响。初次对照优先冻结标题规则和可核验归档字段；现代 LLM 提取若用于历史实验，应明确是回溯研究，不能声称严格复现当时部署。情绪未知不得填成中性，事件未覆盖不得填成零新闻。

## 4. 数据规模与候选替代

两个非代表性样本平均约 5.63 MB/批次；简单乘以 96 批/天约为 0.54 GB/天。这只是下载量级提示，不能据此预测全时期精确容量。筛选能减少最终保存量，但不消除原始下载流量。因此不直接下载多年全量档案，先用有限窗口验证质量与吞吐，再确定连续区间及资源预算。

DOC API 不能直接当作完整导出器：[2018 官方更新](https://blog.gdeltproject.org/doc-2-0-updates-1-5-year-searching-and-updated-mobile-interface/)曾扩展历史搜索，但当前行为本轮未测试，文章列表还有返回上限，不能以零散查询结果声称完整覆盖。

备选官方文档入口：[Crypto News API](https://cryptonews-api.com/documentation)、[CoinDesk Data 新闻接口](https://developers.coindesk.com/documentation/data-api/news_v1_article_list)。它们有历史/时间筛选设计，但本轮未认证、未验证所需年份完整性和使用权益、未开通收费服务；不作为已经可用的数据承诺。

## 5. 建议第一阶段验证与验收

1. 选非保留区间的小窗口，验证资产映射、去重、推广内容处理、覆盖与空窗；首次以 BTC/ETH 验证新闻语义的范围仍待用户确认，不限制其他品种的行情策略能力。
2. 先实现少量可解释数值：窗口事件数、来源数、监管/安全事故等类别计数、事件年龄与覆盖标记。来源或文本不能支撑的情绪/强度不强行生成。
3. 训练与当前推理共用因子定义、特征顺序和时间截止规则，冻结版本；增加因子需新模型，旧 PPO 模型不可直接套用新维度。
4. 同一时序划分和费用下对照价格基线与“价格＋新闻”；报告所有试验与失败，不只挑收益最高结果。
5. 证明训练和模拟实际使用新闻列，并能回溯一次模型动作/风险拦截的输入；同时确认迟到新闻和修订不会改变过去的输入。

新闻 C 的业务目标保留为完整训练/回测/运行能力。覆盖不足时向用户呈现具体受限区间或未支持品种，而不是默默回退成新闻展示页，也不以两份小样本冒充足够的训练数据。
